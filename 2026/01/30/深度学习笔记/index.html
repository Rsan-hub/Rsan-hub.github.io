深度学习笔记

封面为BP算法可视化，来自Understanding Backpropagation | Towards Data Science，作者Brent Scarff。

作业一

1、讲一下深度学习都有哪些组成，以及每一部分你的理解?

  • 数据
    • 定义：数据是深度学习模型的训练素材与评估依据。分为训练集、测试集。
    • 结构特点：数据的结构特点（如向量、网格、序列等）决定了模型的架构。
    • 质量：数据的质量、通用性影响模型效果，这是数据需要预处理与增强的原因。
  • 模型
    • 定义：深度学习模型是一类能基于数据优化参数取值的函数。模型通过多层线性与非线性变换提取输入数据特征，输出预测结果。
    • 模块与参数：深度学习模型由一系列模块堆叠而成，每个模块具有一些可优化参数，可以对数据进行一种特定的线性变换/运算。
      • 常见模块的参数与运算如下：
        • 全连接层(MLP)：权重w、偏置b，线性变换；
        • 卷积层(CNN)：卷积核大小与取值，卷积运算；
        • 自注意力层(Transformer)：wq、wk、wv权重矩阵，注意力机制；
      • 这些运算都属于线性变换，即加权和运算（都满足齐次性与可加性）。因此可以将参数统称为权重与偏置。
    • 激活函数：对线性模块的输出进行一次简单的非线性变换。否则模型只能对数据进行线性变换，没有非线性表达能力，无法拟合数据与预测值之间复杂的非线性关系。
  • 损失函数
    • 定义：损失函数定义了模型预测值与真实值的差异，模型参数调整/网络学习的目标是损失函数最小化。
    • 常见类型：
      • 均方误差(MSE)：用于回归任务。接收一个预测值，计算预测值与真实值的平方差。
      • 交叉熵损失(CE)：用于单标签多分类任务。接收一个预测概率向量（即预测值经过softmax层的输出），计算最高预测概率的负对数。
  • 训练过程
    • 定义：循环更新参数直到模型收敛的过程。分为迭代、周期、训练三个层级。
    • 一次迭代（Iteration）：通过一个批次（Batch）的数据，更新一次模型参数。包括前向传播、反向传播、梯度下降三个步骤。计算该批次数据的平均损失、平均梯度，更新参数。
      • 前向传播：数据输入模型，经过逐层变换，得到预测输出。
      • 计算损失：根据预测输出与真实值，计算该批数据的平均损失，以绘制Loss曲线。
      • 反向传播：利用链式法则计算平均梯度。即从输出层开始，反向计算损失对各层参数的偏导。
      • 优化损失：优化器根据梯度与超参数，调整模型参数，以最小化损失。
    • 一个周期（Epoch）：用不同的 Batch 进行迭代，完整遍历数据集一次。
    • 整个训练（Training）： 重复多个周期，直到模型收敛。
    • 训练过程中，监控和记录的 Loss 曲线是每个训练周期（Epoch）结束后，在整个训练集和验证集上计算的平均损失。但实时观察每次迭代（Iteration）的损失也很有价值。

深度学习两大常见预测任务

回归：预测连续标签；

分类：预测离散标签。

2、为什么神经网络中必须使用激活函数，你都知道哪些激活函数?

让神经网络具有非线性表达能力。如果不复合非线性的激活函数，神经网络就只能对数据做线性变换，模型无法表达输入和输出的非线性关系。

  • 隐藏层：Sigmoid, Tanh, ReLU, Leaky ReLU…
  • 输出层：Sigmoid, Softmax…

3、输出层的激活函数怎么选择?

和损失函数一样，按任务类型选择。

  • 线性回归：正比例函数。
  • 多标签二分类问题：Sigmoid，输出值代表样本属于A类的概率，各输出神经元代表多个不互斥的标签
  • 单标签多分类问题：Softmax，输出值同上，各输出神经元代表单个标签的多种类别，互斥且和为1。

4、梯度是什么?链式求导法则?

  • 定义：梯度是一个 n 维向量，是损失函数 在模型参数空间中某点处，方向导数的最大值，即 增长最快的方向。公式为，其中 是模型所有可学习参数。
  • 链式法则：即复合函数求导法则。
    • 具体而言，计算 对每一层参数的梯度时，不使用数值微分，而是利用后一层已经算出的梯度，反解出前一层所求的梯度，因此叫反向传播算法。
    • 各层梯度的集合，构成一个完整的梯度向量 。
    • 这种算法保存并利用状态 算出的值，递推算出后续状态 的值，体现了动态规划思想。
  • 梯度下降：使用梯度更新模型参数的优化算法。对于每个包含数据点 的训练批次(Batch)，优化器接收一个平均梯度向量 ，并沿着其反方向完成一次完整的参数更新，这个过程叫一次迭代。

5、常见的优化器有哪些?区别?

首先，只要分 Batch ，优化算法要解决的问题就属于随机优化问题。注意两点：

  1. 整个训练集对应一个全局损失函数 ，是真正的最小化目标，而各批次对应的局部损失函数 只是为了计算效率使用的随机近似。
  2. 虽然每个 Batch 迭代的梯度方向 是局部、有噪声的，但如果采样科学，所有 Batch 的期望方向正是全局损失函数的下降方向。

下面是常见的优化器：

  • SGD：随机梯度下降
    • “随机”指每次iteration中，随机采样一个 batch 的数据，使用其梯度平均值更新参数。
    • 缺点：有时梯度的方向不指向 L 最小值方向。
  • Momentum：动量法
    • 动量法在参数更新过程中引入一个历史梯度累积项 。 ，其中 ， 是一个减速因子，通常为0.9。相当于在参数空间各个轴上叠加一个加速度不断减小的加速运动。
    • 累积项 v 使参数在梯度方向一致的维度上加速更新，在梯度方向变化的维度上减少震荡。
    • 核心思想是通过保留过去的更新方向信息，稳定优化过程、提高收敛速度，并使得算法可以跨越一些比较平缓的区域，避免在局部最优停滞。
    • 适合：高曲率、噪声较大的 Loss 函数。
  • AdaGrad：自适应学习率
    • 采用学习率衰减的思想，即随着学习的进行，逐渐减小学习率。
    • AdaGrad 的特点在于：为每个参数分配不同的学习率，依据是参数历史梯度的平方和累积值。导致梯度较大的参数学习率逐渐减小，梯度较小的参数学习率相对较大。
    • 是防止分母为0的小常数。
    • 适合稀疏特征数据。但学习率衰减会导致训练后期步长过短，有更新过慢、提前停止的风险。为此可以采用 RMSProp 方法，逐渐遗忘过去的梯度。
    • 适合：稀疏数据。
  • Adam：自适应学习率+梯度
    • 结合了动量和适应学习率机制，同时估计梯度的一阶矩与二阶矩，并进行偏差校正。
    • 三个超参数：初始学习率 、一次momentum系数 ，二次momentum系数 （标准设定）。
    • 主要优势：收敛速度快、对超参数选择不敏感、对不同任务泛用性强，实际工程常用。
    • 但某些任务中，泛化性能不如SGD。因为 Adam 逐渐减小的学习率可能会导致模型 早期收敛，从而 减少了对训练数据的探索，造成了过拟合的问题。
      • 在 小批量训练 和 高噪声数据集 中，Adam 可能会过于依赖局部最优解，因为它没有像 SGD 那样经历较大的学习率波动和更长时间的训练过程。
      • 通过 SGD + 动量，模型在每个更新步骤中拥有更多的 随机性 和 探索性，即使是 噪声较大的梯度信息 也能引导模型远离局部最优解，保持较好的 泛化能力。

7、神经网络训练中的超参数有哪些?

超参数是模型训练前，由人工设定的控制参数，与模型从数据学习的权重参数相对。调参就是指调超参数。

超参数决定模型的训练过程、最终性能、计算资源消耗情况。包括：

  • 模型：
    • 网络层数/宽度/组件：决定模型表达能力、过拟合风险、适用场景。
    • 权重初始化方式：影响训练初期的信号传播、梯度稳定性。
  • 循环规模：
    • batch size：影响梯度估计精度、训练效率和泛化性能。
      • 这是因为 Bsize 决定了每次迭代的计算量、局部 Loss 对全局 Loss 的近似精度。
      • 计算量大，训练效率低。
      • Loss 近似精度高，梯度估计精度高，噪声少（但容易陷入局部最优），泛化性能较低；Loss 近似精度低，梯度估计精度低，噪声大（但促进跳出局部最优），泛化性能较高。
    • 训练轮数（epoch 数）：决定模型训练的充分程度。
  • 优化器：
    • 学习率：参数更新幅度，影响收敛速度、收敛稳定性。
    • 优化器特有参数（动量系数、学习率调度策略等）：影响参数更新路径、收敛效率。
  • 学习技巧：
    • 正则化系数：限制模型复杂度。
    • Dropout 比例：提升泛化能力。

8、你了解哪些常用的模型评估指标?

一、分类任务

混淆矩阵：由预测结果（P/N）与正确标记（T/F）两两组合构成。是模型预测结果与真实标签的对应关系。

  • 准确率：所有样本中预测正确的样本占比， ，反映模型整体分类性能。
    • 适用：类别较为均衡的任务
    • 不适用：类别不平衡的任务，容易误导（模型只预测负样本，但评估数据负样本远多于正样本）
  • 精确率：预测为正类的准确率， ，反映模型正类预测结果的可靠性。
    • 适用：要求正类高度准确的任务，防正类样本错报。
    • 宁肯放过一千，不可错杀一个。
  • 召回率：模型识别真实正类样本的成功率， ，反映模型对正类样本的覆盖能力。
    • 适用：要求正类覆盖全面的任务，防正类样本漏报。
    • 宁肯错杀一千，不可放过一个。
  • F1值：精确率和召回率的调和平均数， ，衡量模型对正类识别的整体性能。
    • 对较小值更敏感，P或R一项较低，F1显著下降。
    • 权衡兼顾错报和漏报风险。

二、回归任务

  • 均方差（MSE）：方差放大偏差项影响，对离群点敏感。
  • 平均绝对误差（MAE）：方差改为绝对值，更反映模型整体的平均误差，对离群点不敏感。

9、什么是过拟合和欠拟合?解决方法有哪些?

  • 过拟合

    • 定义：模型学习了训练集数据的过多特征，包括噪声与偶然特征，泛化能力太弱。
    • 原因：训练数据量较少；原始特征过多形成噪音；相对训练样本数量而言，模型自由度过大/参数过多/复杂度过强/表达能力过强。
    • 解决方法：
      • 扩充训练集：提高模型对数据分布的覆盖程度。
      • 正则化技巧：
        • 权值衰减：
          • 为损失函数附加一个 Lx 范数作为惩罚函数，以惩罚模型中较大的参数。
          • L₁ 正则化：惩罚权重的 绝对值，使得原本值小的权重变为零，从而产生 稀疏性，并自动进行 特征选择。
            • 去除无关或不重要的特征，在高维数据集上非常有用。
          • L₂ 正则化：惩罚权重的 平方和，倾向于 缩小 权重值，但不会让它们变为零。
            • 通常用于平滑模型，而不是做特征选择。
        • Dropout：随机屏蔽部分神经元，迫使剩下的神经元激活值放大，促使网络不依赖某些特强神经元，更加健壮和鲁棒。
      • 提前停止：监控验证集性能，若 Loss 下降不明显，要及时停止。

  • 欠拟合

    • 定义：模型无法捕捉到数据的一般特征，在训练集、测试集效果都差。
    • 原因：学习到数据的特征过少、模型太简单、正则化（Regularization）过强、训练不充分、数据噪音太大、超参数不合理。
    • 解决方法：增加数据特征数量、模型复杂度，减弱正则化，充分训练，调超参数。提升模型的表达能力和优化效率。

项目一 基于深度学习的葡萄酒质量评分实践

一、深度学习理论

1、损失曲线

训练过程中，损失曲线分为训练损失和验证损失。

  • 训练损失（Train Loss）：在训练集上计算的损失，参与反向传播，更新模型参数。
  • 验证损失（Validation Loss）：在验证集上计算的损失，但不参与反向传播，通常在每个 epoch 后计算。
    • 监控模型在 未见过的数据上的表现，帮助判断模型是否过/欠拟合，用于 模型调优 和 评估泛化能力 。

训练完成后，模型在测试集上输出一个评估结果。

  • 测试集：在训练完成后用于 评估最终模型性能 的数据集，它与训练和验证集无关，用来提供模型在真实场景下的表现。

二、PyTorch 实践

1、Dataset

Dataset 是抽象基类，无法实例化。抽象基类的核心思想：定义接口规范，但不关心怎么实现。

  • 接口规范包括：接口名、传入参数名、属性名等。
  • 不关心具体实现，指接口传入什么数据结构也不关心。
    • 但可以通过抽象属性@property来要求必须有某些属性，或者通过抽象方法签名@abstractmethod间接暗示需要的数据结构。（如规定必须实现索引、长度两个方法，通常就需要传入列表/字典）

总之，抽象基类要求子类必须实现所有抽象方法，但数据结构与实现方法自由。

延伸：类是面向对象编程（OOP）的核心概念。它不仅是数据的容器，更是实现抽象、封装、继承、多态的蓝图。类的核心作用是数学建模，将现实世界或逻辑中的“事物”或“概念”抽象成代码中的实体。
