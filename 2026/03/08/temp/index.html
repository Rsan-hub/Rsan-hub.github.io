基线实验（回顾）

项目 内容
数据 哨兵二号 10 米多光谱（N 通道）
编码器 随机初始化的特征提取网络（轻量卷积层，N→3）
分割模型 SAM3 + LoRA
训练 端到端（编码器与 LoRA 一起优化）

方案 C 概览

维度 内容
启用条件 基线植被类型混淆、阴影绿地漏提；继续使用哨兵二号（不引入外部数据源）
核心贡献 通过自监督预训练，解决随机初始化编码器导致的光谱语义特征丢失问题
技术手段 ① 自监督预训练自编码器（N→3→N），以语义增强重建为目标；② 丢弃解码器，编码器联合 LoRA 端到端微调
插入位置 整个编码器作为 SAM3 前置模块
核心文献 MAE (He et al., 2022)；MR-MAE (Gao et al., 2023)；FG-MAE (Wang et al., 2024)
训练成本 低。预训练仅涉及轻量编码器，不触碰 SAM3 权重；一张 V100 可跑 batch size 8~16

⚠️ 核心隐患：仅用重建损失的编码器学不到语义特征

这是方案 C 最关键的设计决策，必须正视。

问题的本质：如果预训练目标只是像素级重建（L_recon = L1/MSE(重建值, 原始值)），编码器面对的任务是”把 N 通道信号压缩到 3 通道再还原”，它只需要学会保留光谱统计特征（近似 PCA），而完全不需要理解地物语义。这样的 3 通道表示和随机初始化后端到端训练的差距可能微乎其微。

学术界的三条主流解法：

解法一：替换重建目标（FG-MAE 方向）

针对遥感多光谱影像，直接替换掉”重建原始像素值”这一目标，改为重建语义更丰富的特征：

  • HOG（梯度方向直方图）：捕捉空间结构与边缘语义，对地物形状（建筑、道路、植被边界）有区分能力
  • NDI（归一化差异指数，如 NDVI、NDWI）：显式编码植被/水体光谱差异，与绿地分割任务直接对齐

文献支撑（FG-MAE，Wang et al., IEEE JSTARS 2024）：

针对哨兵二号多光谱影像，FG-MAE 将 MAE 的重建目标替换为 HOG+NDI 的组合。实验证明，在多光谱影像上，重建 HOG 的线性探测精度甚至高于重建原始像素，且 NDI 的引入使编码器直接学到植被/水体的光谱差异，在下游分类任务中取得显著提升。这一方法与哨兵二号绿地分割任务高度吻合，是方案 C 的首选预训练目标设计。

解法二：在编码器端增加语义模仿损失（MR-MAE 方向）

保留像素重建作为低层约束，同时在编码器的中间表示层增加”模仿损失”，让编码器输出对齐到 DINO/CLIP 等预训练模型的语义特征。

文献支撑（MR-MAE，Gao et al., IJCV 2023）：

MAE 在解码器端只有低层像素重建的监督，缺少对编码器语义特征的直接约束，导致表示质量不足且预训练收敛慢。 MR-MAE 提出将高层监督（DINO/CLIP 模仿损失）施加在编码器的可见 token 上，将低层重建施加在解码器的 masked token 上，两类目标作用于不同的 token 分区，避免了语义冲突，在 ImageNet-1K 上仅用 400 epoch 就超越了 1600 epoch 的原始 MAE。

⚠️ 对本实验的适用性说明：MR-MAE 中的”教师模型”（DINO/CLIP）是通用视觉模型，其语义特征不一定对齐遥感绿地分类的类别体系。若使用此方向，建议用遥感预训练模型（如 SatMAE、GFM）替代 DINO 作为教师，或用有标签数据训练一个轻量分类头作为弱监督代理。

解法三：多任务预训练（Semantic Genesis 方向）

在重建损失基础上，叠加一个辅助分类任务（如在潜在空间中预测 patch 所属的语义类簇），迫使编码器的瓶颈特征具备语义区分能力。

文献支撑（Semantic Genesis，Zhou et al.）：

Semantic Genesis 在重建损失之上增加分类损失，分类任务为预测子区域所属的类别（类别由预训练自编码器潜在空间的聚类结果构造），作者认为这些类别蕴含丰富的语义特征。 该方法的优势在于无需外部教师模型，只需在自监督阶段额外运行一次 k-means 聚类。

推荐方案：FG-MAE 方向（解法一）

结合你的实验约束（单张 V100、实验重点是 LoRA 微调 SAM3、仅用哨兵二号），解法一（替换重建目标为 HOG+NDI）最优：

  • 无需教师模型，无额外推理开销
  • NDI 与绿地分割任务的类别体系（乔木/灌草/水面/裸土）直接对应
  • 实现简单，可复用 MAE 框架，仅修改 target 计算逻辑

两阶段流程

阶段一：自监督预训练（无标签哨兵二号影像）
输入：哨兵多光谱 [B, N, H, W]
目标：编码器学会压缩多光谱为语义 3 通道表示
损失：L_recon(HOG) + λ * L_recon(NDI)
输出：保存编码器权重 pretrained_encoder.pth

阶段二：端到端微调（有标签哨兵二号 + OSM 标签）
操作：丢弃解码器，加载预训练编码器，接 SAM3+LoRA
损失：分割交叉熵
输出：最终分割模型

关键问题 Q&A

Q1：预训练数据集需要多大？

  • 自监督预训练对数据量要求低，几百到几千张无标签切片即可。
  • 可直接复用微调阶段的训练集（去掉标签），无需额外采集数据。

Q2：lambda_ndi 如何调？

  • 建议消融：λ ∈ {0.3, 0.5, 0.7}，以微调后的 mIoU 为准则。
  • 经验上对绿地/植被为主的任务，λ=0.5 是合理起点（HOG 与 NDI 各占一半）。

Q3：编码器深层是否应该在微调阶段全程可训练？

  • 推荐：冻结浅层（conv1），解冻深层（conv2 + compress）+ LoRA。
  • 理由：浅层已学到通用低层特征（梯度/纹理），过拟合风险低；深层与 SAM3 接口直接相关，需要适配下游任务。
  • 若标注数据量极少（<100 张），可冻结整个编码器只训练 LoRA。

Q4：HOG 目标在 CNN 编码器上有效吗？

文献支撑（FG-MAE，Wang et al. 2024）：

FG-MAE 在多光谱影像上的实验表明，重建 HOG 的线性探测精度高于重建原始像素，证明 HOG 作为重建目标可以有效引导编码器学习更具判别性的空间结构特征，即使是轻量 CNN 编码器。

Q5：只用重建损失能不能用于消融基线？

  • 可以，且强烈建议将”仅重建像素（L_recon=L1）”作为消融对照组。
  • 预期结论：纯重建损失 ≈ 随机初始化端到端训练，从而反向证明 HOG+NDI 目标设计的有效性，这本身就是方案 C 的一个有价值的消融实验结论。
