70. 爬楼梯

参考：70. 爬楼梯 | 代码随想录、力扣题目链接

思路：假设 dp[i-1] 已知

推公式的关键:

  1. 紧扣 dp[i] 定义。
  2. 假设先前的 dp[i-1] dp[i-2] 已知。

dp[i] 定义：爬到第 i 层有 dp[i] 种方法。

从定义可以看出，dp[i] 可以有两个方向推出来。

首先是 dp[i - 1]，上 i-1 层楼梯，有 dp[i - 1]种方法，那么再一步跳一个台阶，不就是 dp[i]了么。

还有就是 dp[i - 2]，上 i-2 层楼梯，有 dp[i - 2]种方法，那么再一步跳两个台阶，不就是 dp[i]了么。

那么 dp[i]就是 dp[i - 1]与 dp[i - 2]之和！

所以 dp[i] = dp[i - 1] + dp[i - 2] 。

其实就是斐波那契数列。

746. 使用最小花费爬楼梯 ✅

参考：746. 使用最小花费爬楼梯 | 代码随想录、力扣题目链接

思路：紧扣定义推初值

  • dp[i]：跳到 i 号楼梯的总花费。
  • 和上题一样，可以跳一步或两步。
    • 即：dp[i] 可以由 dp[i-1] 或 dp[i-2] 推出来，具体取决于谁的价格更小。
  • 初始可以直接站在 dp[0] 或 dp[1] 上，而根据定义，站楼梯不花费体力。因此dp[0]=dp[1]=0。

严格按步骤分析！本题如果先分析遍历方向，从后往前遍历，会掉到坑里，非常繁琐。

本题也可以 S(n) 优化，这里用不优化写法。

Day 2 DP基础2

62. 不同路径

参考：62.不同路径 | 代码随想录、力扣题目链接

思路：二维数组

定义：dp[i][j] 是从起点出发，到达第[i][j]格的路径数。

递推：两种情况，要么从左边来，要么从上面来。递推公式：dp[i][j] = dp[i-1][j] + dp[i][j-1]。

初始化：第 0 行和第 0 列都只有 1 种情况，初始化为全 1。

特别注意变长二维数组初始化，在堆上分配内存，只能用 vector。

初始值 dp[m][0] = dp[0][n] = 1

思路：紧扣定义推特值

比上题多一个障碍物。要考虑障碍物代表什么特值。

dp[i][j] 是从起点出发，到达第[i][j]格的路径数。

而根据定义，起点出发无法到达障碍物，所以障碍物格子的路径数为 0。

另外，本题的细节，就是两种阻断情景，有不同的代码表达。

第一种阻断，如果第 0 条边有了障碍，路就被堵住了，所以障碍之后的 dp[i][0] 应该还是初始值 0。如下图。

用代码表达，就是不满足条件跳出循环 = 阻断一行。

第二种阻断，如果递推过程中有障碍，就只堵住一格，障碍后格子该是啥是啥。

用代码表达，就是不满足条件继续循环 = 阻断一格。
