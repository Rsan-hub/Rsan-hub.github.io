一、哈希综合

1. 供暖器-二分

方法：二分答案

难点：check函数 双指针

二分法 + 双指针

本题思路：直接求解最小半径似乎无从下手，因为半径和覆盖关系交织在一起。但如果我们每次猜一个半径，验证它是否能覆盖所有房屋，就比较简单。

这个 guess + check 的验证过程，叫决策性算法（或判定性算法转化）。

用二分法 guess 的决策性算法，叫二分答案。

解题的时候往往会考虑枚举答案然后检验枚举的值是否正确．若满足单调性，则满足使用二分法的条件．把这里的枚举换成二分，就变成了「二分答案」．

—— OI Wiki

二分答案

卡哥的区间定义是二分法的实现细节，本题是二分法的选用场景。即：当求“最小值”或“最大值”，且所求变量具有单调性时，二分答案往往最直接。

单调性：变量单调递增/减；且存在一个阈值，使得变量在阈值一侧均不可行，在另一侧均可行。

二分搜索就是上面说的 guess，用来搜这个阈值。

二分答案的核心步骤：

  1. 确定答案的单调性，从而明确搜索范围。
  2. 二分猜测一个候选答案，并设计一个高效的 check 验证函数来验证该答案是否可行。
  3. 根据 check 结果收缩搜索区间，最终找到最优解。

❗️其中验证函数最难写。

总结本题思路

  • 从“求最小半径”入手，意识到直接求解困难 → 尝试二分答案。
  • 发现半径的单调性 → 确定二分可行。
  • 考虑如何快速验证 → 利用排序 + 双指针，将验证复杂度降至线性。

验证函数双指针

第二个难题就是验证函数，怎么用双指针实现线性复杂度。

本题属于追赶指针大类：一个指针遍历主数组（房屋），另一个指针在辅助数组（供暖器）中单向移动，为每个主元素找到最佳匹配。这种模式要求两个数组都已排序，且辅助指针不会回退，保证了线性复杂度。

  • 特别注意：内层循环的辅助指针，要手动补一个越界检查。

考虑如何实现 check 函数。

先对 houses 和 heaters 进行排序，使用 i 指向当前处理到的 houses[i]；j 指向 可能 覆盖到 houses[i] 的最小下标 heaters[j]；x 代表当前需要 check 的半径。

当且仅当 heaters[j]+x < houses[i] 时，houses[i] 必然不能被 heaters[j] 所覆盖，此时让 j 自增。

找到合适的 j 之后，再检查 heaters[j]−x <= houses[i] <= heaters[j]+x 是否满足，即可知道 houses[i] 的覆盖情况。

2. 有效三角形的个数-二分

方法：排序 + 双指针

难点：双指针移动，计数优化 + (r - l)

参考：两数之和 三数之和【基础算法精讲 01】

思路

n 数之和套皮，详见 T17。

暴力解法：三重循环，必然超时。于是先排序，再利用有序性质优化。

搜索有序数组的优化方法：

  • 二分法：一重 → 一重循环，O(n) → O(logn)
  • 双指针：两重 → 一重循环，O(n^2) → O(n)

所以二分法只能替换一层循环(最内层)，而双指针可以替换两层循环(内两层)。

注意两种方法的指针移动！

二是条件优化：

如果规定：三条边长从小到大为 a、b、c，则只需要 a + b > c 就能组成三角形。

对比：

  • 供暖器：二分答案(ans取值空间)。适用于知道答案范围，且答案具有单调性，如“最小化最大值”。
  • 三角形个数：用双指针、二分法替换 for 循环，降低复杂度。适用于有序数据，优化枚举效率。

17. 四数之和

方法：排序 + 固定 + 双指针、去重

难点：去重逻辑

n 数之和

n 数之和经典解法：双指针优化 n 层 for 循环。

流程：排序 + (外层for)固定前n-2个数 + (内层双指针)找后2个数。

即通过改写内层 for 循环为双指针完成。注意双指针要求数组有序，因此先 sort。

可以用二分法，但是效果不如双指针。原因如下：

  • 二分法：一重 → 一重循环，O(n) → O(logn)，一次确定一个数；
  • 双指针：两重 → 一重循环，O(n^2) → O(n)，一次确定两个数。

去重逻辑

去重的目的：避免因相同元素导致重复解。分为 for 循环去重和双指针去重。

核心思想：对于每一个指针，跳过所有与当前 nums[ptr] 值相同的元素。

32. 最长有效括号 - 力扣 - powcai 的解法

括号匹配问题一般都是使用栈。

注意：括号匹配不一定要往栈里装括号！可以匹配条件用括号，栈里元素装下标。

我们先找到所有可以匹配的索引号，然后找出最长连续数列！

例如：s = “)()((())”，我们用栈可以找到，

位置 1 和位置 2 匹配，

位置 5 和位置 6 匹配，

位置 4 和位置 7 匹配。

这个数组为：1,2,5,6,4,7 这是通过栈找到的，我们按递增排序！1,2,4,5,6,7

找出该数组的【最长连续子数组】长度，就是最长有效括号长度！本例为 4。

所以时间复杂度来自排序：O(nlogn)。

—— 作者：powcai

71. 简化路径 - 力扣 - 宫水三叶的解法

切分最小单位，再入栈

要处理串中任意多个连续的斜杠/点。属于就近匹配，连续消除等，一般用栈的 LIFO 特性。

但重点是切分 path，这样就能每次以一个 item 为入栈单位，比字母为单位更方便。

这也是 stack<type> 作为栈比 string 作为栈的优越性：入栈元素粒度大。

根据 item 为何值进行分情况讨论：

  • item 为有效值 ：存入栈中；
  • item 为 .. ：弹出栈顶元素（若存在）；
  • item 为 . 或空：不作处理。
